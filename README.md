# 한국어 감정 분석
한국어 문장 데이터를 두 단계로 감정 분류하는 딥러닝 기반 자연어 처리 모델
GRU 모델: 3단계(긍정/중립/부정) 감정 분류

KoBERT 모델: 6단계(기쁨/당황/분노/불안/상처/슬픔) 감정 세부 분류

## GRU
- RNN(Recurrent Neural Network, 순환 신경망) 계열의 한 종류로, **연속적인 데이터**(대표적으로 텍스트, 음성, 시계열 데이터)를 처리하기 위해 고안된 딥러닝 모델
- RNN은 기본적으로 앞 단의 출력을 뒤 단의 입력에도 함께 주면서, “순서”가 있는 데이터를 처리하는데, **장기 기억(문맥 유지)력**이 약한 문제가 있다.
- GRU는 이러한 RNN의 한계를 해결하려고 만들어진 구조로, 게이트(gate)라고 불리는 구조를 활용해 중요한 정보만 골라 오래 기억하고 필요 없는 정보는 버리는 특징
- 학습 방식
	- 입력 데이터(문장)를 GRU 신경망에 입력
	- 정답 레이블('긍정/중립/부정')을 같이 준비
	- 파라미터(가중치)가 랜덤하게 초기화된 GRU 신경망은 입력 데이터로부터 정답을 예측하려고 시도
	- 예측값과 실제 정답 레이블의 차이(오차)를 계산하고, 이 오차가 최소가 되게 신경망의 파라미터를 조금씩 조정하면서 학습

## KoBERT
- SKT에서 공개한 “한국어 최적화 BERT 모델”(BERT: Bidirectional Encoder Representations from Transformers)
- 엄청나게 큰 한국어 말뭉치로 사전학습되었으므로, 한국어 문맥 파악력이 매우 뛰어난 트랜스포머 기반 딥러닝 모델
- 단어 단위가 아니라 “서브워드”로 텍스트를 쪼개어, 신조어나 띄어쓰기 오류 등이 있어도 매우 잘 대응
- 학습 방식
	- 미리 준비한 데이터셋의 문장들과 정답 감정 레이블(0~5, 예: 기쁨~슬픔)을 KoBERT에 입력
	- 예측값과 정답 사이 오차를 계산
	- 오차를 줄이도록 KoBERT와 분류기 레이어의 파라미터(가중치)를 역전파로 조금씩 수정
	- 이 과정을 데이터 전체(에폭 단위) 여러 번 반복 (수천~수만 번)
